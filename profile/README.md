## 🧪 Projects

### 🖧 IPGetter
- **Language**: Java  
- A tool that converts domain names (like `google.com`) into their current IP addresses.
- Example: `google.com → 142.250.64.78`

### 🖥️ os-portfolio
- **Tech Stack**: HTML, CSS, JavaScript  
- A personal portfolio styled to look like a desktop operating system, complete with windowed UI and sound effects.

### 💻 cmd-portfolio
- **Tech Stack**: HTML, CSS, JavaScript  
- A command-line style portfolio where visitors can type commands to view details, simulating a terminal interface.
